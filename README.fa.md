# دبیر جلسه — نسخه عمومی ۱.۰

نسخه ۱.۰.۰؛ راهنما و ابزارهای کمکی برای استفاده در دستیارهای سازگار با اسکیل.

این بسته چرخه کامل جلسه را پوشش می‌دهد: آماده‌سازی، دستور جلسه، پاسخ‌گویی خصوصی حین جلسه، صورت‌جلسه مستند، اقدامات قابل پیگیری و پذیرش خروجی بر پایه شواهد.

- بسته خصوصی مدیر از دستور جلسه قابل ارسال جداست.
- تصمیم، پیشنهاد و اقدام با هم مخلوط نمی‌شوند؛ مسئول و موعد نامشخص، نامشخص می‌مانند.
- قالب بر اساس شرکت، حوزه کاری، نوع جلسه و مجموعه سازمان‌های شرکت‌کننده انتخاب می‌شود. تأیید ظاهر با تأیید متن و اجازه ارسال جداست.
- هویت بصری قابل تنظیم است؛ هیچ لوگو، قالب رسمی یا اطلاعات واقعی شرکتی در بسته وجود ندارد.
- پاسخ حین جلسه باید منبع و محدودیت خود را نشان دهد و خودبه‌خود تعهد ایجاد نمی‌کند.
- پیگیری دائمی فقط وقتی قابل وعده‌دادن است که ابزار ذخیره‌سازی، زمان‌بندی و مجوز لازم واقعاً برقرار باشند.

این بسته راهنما، الگو و آزمون محلی است؛ ضبط‌کننده، سرویس ارسال یا زمان‌بند اجرایی ندارد. نمونه‌ها کاملاً ساختگی هستند. برای استفاده، راهنمای INSTALL.md را بخوانید. آزمون‌ها با Python 3 و بدون وابستگی خارجی اجرا می‌شوند.
