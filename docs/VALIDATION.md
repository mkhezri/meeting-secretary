# Validation and limits

The Python standard-library unittest suite contains 62 offline tests, using synthetic fixtures only. Run the commands in the root README to reproduce them.

Coverage includes revision-specific approval and routing, uncertain-send reconciliation, evidence identity/version and optional digest binding, private audience and stale/conflicting sources, scoped corrections, measured/unknown metrics, exact-context visual approval, participant-set matching, logo provenance and approved text-only branding. Visual approval, minutes-content approval and distribution permission are separate.

The package checker inspects frontmatter, JSON, Python syntax, relative Markdown links, packaging hygiene, empty registry, unconfigured adapters and the MIT license.

The helpers trust supplied fields. They are not production authorization enforcement, identity or consent verification, exhaustive schema validation, or connector implementations. No real recording, transcription, calendar, messaging, storage, scheduler or delivery integration is implemented or validated. Dependency cycles, callbacks and runtime outages are covered in guidance rather than implemented engines.

No legal opinion, exhaustive ownership determination, zero-leakage guarantee or official company formatting certification is implied. Keep real configuration and meeting data outside this public distribution.
